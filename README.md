# swamp-agent-browser-batch

[swamp](https://swamp.club) extension `@mgreten/agent-browser-batch` —
dispatch agent-browser commands as a single subprocess so cookies and
Chromium state persist across every step.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/agent-browser-batch`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under
[extensions/models/](extensions/models/).
